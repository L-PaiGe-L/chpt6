# Matplotlib 坐标轴定制练习项目

这是一个关于Matplotlib坐标轴定制技术的练习项目，包含了多种图表定制技巧的实现和演示。

## 📁 项目结构

```
pl/
├── pl1.m                   # 练习1：股票价格走势图（时间序列刻度定制）
├── pl2.m                   # 练习2：销量图表（主图+嵌入小图）
├── pl3.m                   # 练习3：编程语言投票结果（水平条形图）
├── pl4.m                   # 练习4：二次函数图像（轴脊移动）
├── pl5.m                   # 练习5：正切函数图像（综合定制）
├── EX5 022340502 刘佩.html # 交互式HTML练习页面
├── Matplotlib_轴定制练习.html # 粉紫主题HTML练习页面
├── EX5 022340502 刘佩.ipynb # Jupyter Notebook版本
└── README.md               # 本文档
```

## 🎯 练习内容

### 练习 1：定制刻度位置、格式与样式
- **文件**: `pl1.m`
- **内容**: 使用48小时股票价格数据绘制折线图
- **重点**: 
  - X轴主刻度每12小时，格式为YYYY-MM-DD HH:MM
  - X轴次刻度每2小时
  - 主刻度朝外（蓝色），次刻度朝内（红色）
  - 添加网格线和合理标题

### 练习 2：添加图内坐标轴
- **文件**: `pl2.m`
- **内容**: 全国及华东区销量数据可视化
- **重点**:
  - 大图展示全国总销量（蓝色方形标记）
  - 嵌入小图展示华东区销量（红色圆形标记）
  - 小图刻度标签缩小避免拥挤

### 练习 3：隐藏部分轴脊
- **文件**: `pl3.m`
- **内容**: 编程语言受欢迎程度投票结果
- **重点**:
  - 隐藏顶部和右侧轴脊
  - 隐藏Y轴刻度线
  - 为条形图添加得票数值标签

### 练习 4：移动轴脊到数据中心
- **文件**: `pl4.m`
- **内容**: 二次函数 y = x² 图像
- **重点**:
  - 隐藏顶部和右侧轴脊
  - 将轴脊移动到坐标原点 (0,0)
  - 等比例坐标轴设置

### 练习 5：综合定制
- **文件**: `pl5.m`
- **内容**: 正切函数 y = tan(x) 图像
- **重点**:
  - 轴脊移动和刻度定制结合
  - Y轴范围限制 [-4, 4] 避开无穷大奇点
  - X轴刻度使用LaTeX格式标签

## 🚀 使用方法

### 运行MATLAB脚本
```matlab

run('pl1.m')  % 股票价格走势图
run('pl2.m')  % 销量图表

1. 直接在浏览器中打开 `.html` 文件

npx serve .

3. 访问 `http://localhost:8000/EX5 022340502 刘佩.html`

```
